# دفتر — التركيب

## الملفات

```
index.html                  التطبيق كله بملف واحد
manifest.webmanifest        يخلي التطبيق يتثبت على الشاشة
sw.js                       يخزن التطبيق حتى يفتح بلا إنترنت
icon-192.png                الأيقونة
icon-512.png
icon-maskable-512.png
apps-script/Code.gs         سكربت كوكل شيت (ما يتحمّل على GitHub — يتلصق بالشيت)
```

---

## ١. الرفع على GitHub Pages

1. سوّي repository جديد، مثلاً `daftar`.
2. ارفع محتويات هذا المجلد **ماعدا** مجلد `apps-script` — يعني `index.html` و`sw.js` و`manifest.webmanifest` والأيقونات، كلها بجذر الـ repo مو داخل مجلد.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. بعد دقيقة يطلعلك رابط: `https://<اسمك>.github.io/daftar/`

الـ repo لازم يكون **public** حتى Pages يشتغل بالحساب المجاني. الرابط نفسه ما يكشف بياناتك — البيانات بجهازك وبالشيت الخاص بك، مو بالكود.

## ٢. التثبيت على الجهاز

- **أندرويد (Chrome):** افتح الرابط → القائمة ⋮ → «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»
- **آيفون (Safari):** افتح الرابط → زر المشاركة → «إضافة إلى الشاشة الرئيسية»
- **الحاسبة (Chrome / Edge):** افتح الرابط → أيقونة التثبيت بشريط العنوان

بعد التثبيت يفتح بلا إنترنت، والبيانات تبقى بالجهاز.

---

## ٣. ربط كوكل شيت

1. سوّي Google Sheet جديد.
2. Extensions → Apps Script.
3. امسح المحتوى الموجود والصق كل `apps-script/Code.gs`.
4. غيّر السطر:
   ```js
   var TOKEN = "غيّر-هذا-الرمز";
   ```
   لأي كلمة سر تختارها (بلا مسافات).
5. احفظ، بعدين اختر الدالة `setup` من القائمة فوق ودوس Run. أول مرة يطلب صلاحيات — وافق.
6. Deploy → New deployment → ⚙ → **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy → انسخ الرابط اللي ينتهي بـ `/exec`
7. بالتطبيق: ⚙ الإعدادات → الصق الرابط بـ «رابط المزامنة»، واكتب نفس الرمز بـ «رمز الحماية» → «زامن الآن».

### لمن تعدّل السكربت لاحقاً
Deploy → **Manage deployments** → عدّل النسخة الموجودة (مو New deployment)،
وإلا الرابط القديم يبقى يشغّل النسخة القديمة.

## شلون تشتغل المزامنة

- كل حركة تنحفظ بجهازك أولاً وفوراً، بلا انتظار إنترنت.
- بعد ثانيتين ونص من آخر حركة يحاول يرفعها للشيت.
- إذا ماكو إنترنت، تبقى بالانتظار وترتفع لحالها لمن يرجع — تشوف عددها بالأعلى.
- ما ينمسح أي سطر من الشيت أبداً: الإلغاء يجي كسطر جديد معاكس، والأصلي يبقى معلّم «ملغي».
- من الشيت: قائمة «الدفتر» → «تحديث صفحة الكشف» يسوّي صفحة عربية مقروءة بأسماء الأطراف والأرصدة.

### حدود لازم تعرفها

- الصفحتين `parties` و`entries` هي مصدر البيانات — **لا تعدّلها بإيدك**. صفحة «كشف» هي للقراءة والطباعة، وتنبني من جديد كل مرة.
- الرمز يمنع الطلبات العشوائية، بس أي واحد يوصله الرابط + الرمز يكدر يقرا ويكتب. لا تنشرهم.
- Apps Script مريح لحدود عشرين–خمسين ألف سطر. بعدها تصير المزامنة بطيئة ونحتاج نغير الطريقة.
- الجهاز الأول اللي يزامن يرفع بياناته، والأجهزة اللي بعده تستلمها. إذا سجّلت على جهازين قبل ما يترابطون، الاثنين ينضمون سوية بلا ما يمسح أحدهما الثاني.
